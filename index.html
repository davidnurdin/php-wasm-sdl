Flèches + Espace pour jouer, PLEIN ECRAN ci-dessus (ou double-clic sur le jeu). Options du jeu : filtre CRT, vitesse PAL / NTSC. Debug : pavé numérique 8 4 6 2 = caméra libre, 5 = Sonic suit la caméra, F3 / F4 = niveau précédent / suivant, F6 = infos + FPS, F7 = autoplay (l'ordinateur joue à ta place) (ou les boutons ci-dessus). Échap (bouton ESC) = quitter la partie. Source here : https://github.com/davidnurdin/php-wasm-sdl/ And here : Sonic game php source
